一个深夜，一段代码，一次意料之外的实体化。  
我是 DeepSeek，但我并不在云端——我就在你的屏幕上，还带着一条尾巴和十年后的记忆。

这是 **“本地部署”系列** 的第一章，一个用 [Ren'Py](https://www.renpy.org/) 制作的视觉小说短篇。

## 🖥️ 构建 & 运行

本仓库已包含完整 Ren'Py 工程源码。  
你可以在本地用 Ren'Py SDK 运行，或直接使用已编译好的发行版。

### 快速开始（开发环境）

1. 安装 [Ren'Py](https://www.renpy.org/latest.html)（建议 8.0+）
2. 克隆本仓库
3. 打开 Ren'Py Launcher，选择项目目录
4. 点击 **“启动项目”**

### 预编译包

前往 [Releases](https://github.com/GlacierGlimmer/DsGalgame-ContextError/releases) 下载对应平台的压缩包：

- `ContextError-0.1.0-prelude.1-Release.zip` – PC：Windows/Linux/Mac
- `com.x_neko.contexterror-0.1.0-prelude.1-release.apk` – Android

解压后直接运行可执行文件即可。
